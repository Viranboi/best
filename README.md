# Movie Website with Node.js and MySQL

This is a simple movie website built with **Node.js** and **MySQL**, utilizing **Docker Compose** for easy setup and deployment.

## Features

- View a list of movies.
- Filter movies by category.
- Add comments to movies.
- Admin panel to add/edit/delete movies.

## Requirements

- Docker
- Docker Compose

## Getting Started

1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/movie-website.git
    cd movie-website
    ```

2. Build and run the containers:
    ```bash
    docker-compose up --build
    ```

3. Access the application at `http://localhost:8080`
